Este documento describe únicamente funciones verificadas en el código fuente actual. Toda limitación se identifica de forma expresa.

Modelo de amenazas

  • Suplantación de sesión/rol.
  • Acceso entre cooperativas.
  • Aceptación concurrente de viajes.
  • Exposición de documentos o comprobantes.
  • Manipulación de pagos, zonas o campañas.
  • Abuso de tokens push o secretos.

Datos personales

Aplicar minimización: soporte y comercial solo acceden a datos necesarios. La eliminación de cuenta se gestiona desde la URL pública y conserva únicamente información requerida por integridad, seguridad o retención publicada.

Archivos

  • Validar MIME, tamaño y extensión.
  • No confiar en el nombre de archivo.
  • Servir mediante endpoint autorizado o URL temporal.
  • Permitir imagen/PDF donde el flujo lo admite.

Auditoría

Roles, zonas, documentos, membresías, pagos, conciliaciones y campañas generan eventos relevantes con actor, entidad, acción, fecha y motivo.
