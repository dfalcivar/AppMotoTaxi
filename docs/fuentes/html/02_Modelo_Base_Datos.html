Principios

  • PostgreSQL es la fuente transaccional.
  • PostGIS soporta zonas Polygon/MultiPolygon y validación espacial.
  • Los cambios se aplican mediante migraciones idempotentes.
  • Entidades históricas se archivan o desactivan cuando corresponde; no se destruyen para ocultarlas.

Relaciones principales

Usuarios mantienen capacidades móviles acumulables. Las relaciones por mototaxi separan OWNER_MANAGER de AUTHORIZED_DRIVER y las jornadas determinan qué unidad conduce cada persona. Viajes conservan paradas, eventos y cancelaciones; membresías, fiscalidad y publicidad separan órdenes, pagos, conciliación y documentos históricos.
