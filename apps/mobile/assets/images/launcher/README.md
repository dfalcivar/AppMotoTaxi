# Iconos de lanzamiento Costa-Go v2

- `costa-go-launcher-foreground-v2.png`: capa transparente del ícono adaptativo.
- `costa-go-launcher-monochrome-v2.png`: silueta para íconos temáticos de Android 13 o superior.
- `costa-go-launcher-legacy-v2.png`: fuente del ícono Android para dispositivos anteriores.
- `costa-go-play-store-512-v2.png`: recurso de 512 x 512 listo para cargar en Google Play Console.

El fondo adaptativo se define en `pubspec.yaml` con el color `#F4F8FB`. No se deben agregar esquinas redondeadas a estas fuentes: Android y Google Play aplican la máscara correspondiente.
